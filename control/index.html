Twitch

Quick guide: You may authorize either the streamer's account (messages will appear as the streamer) or a separate bot account (messages appear from the bot). See the note below before connecting.

Streamer vs Bot account
  • Streamer account: Authorize the streamer to make the bot send messages as the streamer (useful if you want requests to appear from the streamer). This requires the streamer to sign in.
  • Bot account: Create a dedicated bot account, authorize it, and it will send messages as the bot. This is recommended for production since it separates broadcaster credentials from bot activity.
Not connected

Note: The Client Secret is temporarily stored in your browser during authorization and then persisted to the server in data/twitch.json so the server can automatically refresh tokens. Keep that file secure or use the Disconnect button to remove stored credentials.

Settings

When enabled (default), requests made via Twitch chat will be placed ahead of any requests added from the control panel (streamer), but behind other viewer requests.

When disabled, chat users cannot add songs to the queue. The streamer can still add requests from the control panel.
