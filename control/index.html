Network

The IP address both HTTPS servers listen on. 0.0.0.0: other computers on your LAN can connect using this PC's address (e.g. https://192.168.1.50:3001). 127.0.0.1: only this computer can connect. Picking a specific LAN IP restricts access to that one address. Changing the address regenerates the self-signed certificate, so browsers will show the trust warning again after a restart.

The two ports must be different and both must be free for the servers to start. Ports below 1024 may require administrator privileges.

Network changes are saved immediately but only take effect after you press Restart Server. After a successful restart this page will automatically open the control panel at its new address and port.

Twitch

Quick guide: You may authorize either the streamer's account (messages will appear as the streamer) or a separate bot account (messages appear from the bot). See the note below before connecting.

Streamer vs Bot account
  • Streamer account: Authorize the streamer to make the bot send messages as the streamer (useful if you want requests to appear from the streamer). This requires the streamer to sign in.
  • Bot account: Create a dedicated bot account, authorize it, and it will send messages as the bot. This is recommended for production since it separates broadcaster credentials from bot activity.
The bot posts usage instructions in chat every N minutes. Set this to 0 to disable automatic reminders; viewers can still use !help at any time.
Not connected

Note: The Client Secret is temporarily stored in your browser during authorization and then persisted to the server in data/twitch.json so the server can automatically refresh tokens. Keep that file secure or use the Disconnect button to remove stored credentials.
